## ภาพรวมที่เจอ

**จุดแข็ง:**

- Trigger กันจองชนฝั่ง DB ออกแบบดี (advisory lock + ตรวจ capacity รายชั่วโมง + daily ข้ามวันหยุด)
- RLS เกือบครบทุกตาราง, SECURITY DEFINER ทุกตัวตั้ง `search_path` แล้ว
- Service role key ไม่รั่วฝั่ง client (ใช้ที่เดียวคือ `/api/signup` ฝั่ง server)
- โค้ดโดยรวมสะอาด ไม่มี dependency ฟุ่มเฟือย

**จุดวิกฤต:** มีช่องโหว่ account takeover 1 จุด (เฟส 0.1) และกับดักหลายจุดที่ต้องเคลียร์ก่อนขายจริง
