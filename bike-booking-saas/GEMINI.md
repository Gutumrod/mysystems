# Antigravity Workspace

พื้นที่ทำงานเฉพาะสำหรับ Antigravity (AI Coding Assistant) เพื่อความเป็นระเบียบเรียบร้อยและไม่ให้โฟลเดอร์ภายนอกรกครับ

## Conventions (ข้อตกลงในการทำงาน)
- **Language**: Use TypeScript for web projects.
- **Styling**: Prefer Vanilla CSS for styling.
- **Structure**: Keep everything clean, modular, and organized inside this workspace.
